# Data and code licensing

The HotpotQA dataset is distributed under the Creative Commons Attribution-ShareAlike 4.0 license, according to its [Hugging Face dataset card](https://huggingface.co/datasets/hotpotqa/hotpot_qa). The saved pilot CSV contains selected questions and evidence passages derived from HotpotQA. Attribute the source dataset to Zhilin Yang et al., “HotpotQA: A Dataset for Diverse, Explainable Multi-hop Question Answering,” EMNLP 2018, [ACL Anthology](https://aclanthology.org/D18-1259/), and retain the dataset license notice when redistributing the derived records.

No separate license has been selected for the experiment code in this repository. Unless the author adds a code license, the code remains subject to the default copyright rules; public visibility alone does not grant reuse rights.
